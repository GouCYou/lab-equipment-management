# 对话界面与消息编辑

用户消息采用统一 20px 圆角，内边距 14px / 18px；清除段落默认外边距，空附件不占位。编辑和重试采用现有紫色主题及 Phosphor 图标。悬停或键盘聚焦时显示编辑按钮；触屏保留可见入口。

编辑支持取消、保留附件、完成并发送。服务端从选定消息之前的上下文创建新对话继续，原对话与既有业务操作保留。失败重试沿用原 run ID，保留操作幂等键，不重复插入用户消息；执行中的状态查询失败则继续查询原请求。

对话区域仅显示“请求失败，请重试”和重试按钮，不展示供应商错误详情。后台仍保留诊断信息。

验证：前端 8 项、Java/MySQL 18 项通过，生产构建通过；独立测试库 10 条 HTTP 工作流通过。浏览器验证取消编辑、修改后提交、原消息保留及直接重试。界面截图见 validation/chat-edit-2026-11-08.png 与 validation/chat-retry-2026-11-08.png。

后续界面调整：编辑图标位于用户消息下方右侧；移除回复前的 Logo 与项目名；重试按钮置于提示文字下方左侧；完整回复底部左侧提供复制图标。复制支持 HTTPS/localhost Clipboard API 与局域网 HTTP 兼容路径，并反馈成功状态。“问问 AI”按钮图文间距为 8px。前端共 10 项测试通过，构建通过；浏览器核对编辑、重试位置和按钮间距，并确认复制成功反馈。

重试反馈补充：实际诊断发现供应商曾约 0.2 秒即返回失败，原页面迅速恢复原样。重试现在保留至少 650ms 的可见加载状态，禁用重复点击，并区分重试中与重试未成功。浏览器实测后续重试成功返回设备查询结果。

时间展示按北京时间的自然日计算：今天时分、昨天、前天、3–7 天前、超过一周日期时间、超过一年带年份。未来日期仍显示日期，避免混淆预约时间。对话三点菜单支持置顶/取消置顶、重命名、删除；V8 迁移保存置顶时间。前端 19 项、Java/MySQL 19 项及隔离库 10 条 HTTP 工作流通过。

聊天样式移植：参考 short-video-agent 的 ConversationView.vue、ConversationTurn.vue 与 style.css，使用同样的紧凑输入框布局、Element Plus 自动增高输入区、附件与圆形发送按钮、消息图标操作栏、失败警告及重新生成状态；保留博仪配色和设备图片/实验室范围功能。删除原自定义重试文案、胶囊按钮和旧输入框样式。

发送状态改为乐观更新：普通发送立即清空输入并展示消息；编辑提交立即替换该条消息并移除其后的旧回复、卡片和错误状态。原持久化对话仍保留，服务端创建上下文分支。新增延迟接口测试验证在接口未返回时就已更新画面。重命名单独使用单行 input，Enter 提交；其他原因填写保留多行。

本轮前端 22 项测试与生产构建通过。浏览器验证单行标题与 Enter、编辑后即时清空旧回复、参考输入框和重新生成状态。桌面 1440×900 核对后恢复默认预览尺寸。截图 reference-composer-2026-11-08.png、reference-regenerating-2026-11-08.png、rename-single-line-2026-11-08.png。
