## HTTP 闭环

报告见 [validation/http-integration.json](validation/http-integration.json)。通过真实接口完成：

1. 创建多角色账户、实验室与设备。
2. 请求幂等、拒绝客户端替换业务身份、本人及实验室隔离。
3. 两个实验员操作并发批准重叠预约，仅一条成功。
4. 并发发放同一预约，仅生成一条未归还借用。
5. 上传真实 PNG 文件、验证附件权限，AI 工具调用 Java 完成归还并释放占用。
6. 故障核实禁借，未领取的已批准预约失效。
7. 分派、维修、过程记录、验收退回与通过，多故障和手工停用互不覆盖。
8. AI 总结借还、工单和利用率，学生不能调用管理统计。
9. 实际 Qdrant 索引和过滤检索、知识审核发布、引用和停用。
10. 真实模式缺模型配置明确失败，无服务密钥拒绝内部调用。

AI 此轮使用显式 demo；生成文字与 Embedding 为合成测试数据。数据库、Redis、Qdrant、文件、鉴权、工具回调、状态变更是真实执行。不能用此结果声称真实视觉识别准确率或真实 RAG 质量。
